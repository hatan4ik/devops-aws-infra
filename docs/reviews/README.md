# Historical review archive

This directory is not a current work queue. Its reports are point-in-time
evidence and may describe source, decisions, paths, or findings that have since
changed.

Use [Project status](../PROJECT-STATUS.md), the [ADR index](../adr/README.md),
and current source to decide what is true now. Before acting on any historical
finding, reconcile it against those authorities and record the result in the
relevant current delivery change.
