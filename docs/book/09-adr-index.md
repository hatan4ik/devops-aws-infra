# Chapter 9 — Architecture Decision Records

**Status:** Navigation page only. The canonical decision index is
[`docs/adr/README.md`](../adr/README.md).

This chapter deliberately does not duplicate ADR titles, statuses, or decision
summaries. Duplicate indexes drifted when the platform moved from the historical
Control Tower/AFT proposal to direct Terraform-managed AWS Organizations
delivery.

Use the canonical [ADR index](../adr/README.md) for every decision, including
current supersession status. In particular,
[ADR 0019](../adr/0019-direct-organizations-account-vending.md) supersedes ADR
0001 for account vending, and
[ADR 0014](../adr/0014-canonical-architecture-and-iac-boundary.md) defines the
active/candidate source boundary.
